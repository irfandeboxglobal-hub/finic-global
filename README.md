# Finic Global Solutions — Next.js Enterprise Website

A high-performance B2B technology services and software platform website for **Finic Global Solutions**, built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## ⚡ Quick Start

### 1. Development Mode
Run the Next.js development server with Turbopack:

```bash
npm run dev
```

Visit the local development site at:
**[http://localhost:5173](http://localhost:5173)**

### 2. Production Build & Start
Compile static pages and start the production server:

```bash
npm run build
npm start
```

## 🛠 Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router with Partial Prerendering & Static Generation)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict typing across data models and props)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom design tokens and glassmorphic utilities
- **Icons**: [Lucide React](https://lucide.dev/)
- **Assets**: Authentic high-resolution WebP product mockups, illustrations, and official company logos

---

## 📱 Features

- **Floating AI Assistant**: Docked bottom-right interactive chatbot widget with prompt shortcuts and knowledge answers.
- **Glassmorphic Navigation**: Sticky responsive navbar with interactive Services and Products dropdowns.
- **Mobile Drawer**: Touch-friendly slide-in menu for smartphones and tablets.
- **Static Site Generation (SSG)**: 31 statically pre-rendered routes generated in under 3 seconds for sub-second page loads.
- **SEO & Social Cards**: Dynamic metadata tags, OpenGraph descriptions, and favicon assets across every route.
